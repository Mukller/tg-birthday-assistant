## [1.0.0] - Initial release
### Added
- Initial release of tg-birthday-assistant
- Telegram userbot (MTProto/GramJS) integration
- Birthday reminders with flexible scheduling (BullMQ)
- Contact import from Telegram dialogs
- AES-256-GCM encrypted session storage
- Multi-rule reminder system (7/3/1/0 days + custom)
- Draft congratulations with history and preview
- Export/import (JSON/CSV/NDJSON)
- Admin panel for authorized users
- Health endpoint and CI via GitHub Actions
